Project Section

Airlines Reservation System

The Airline Reservation System is a software application designed to help users search for flights, view available seats, and make reservations. The system allows passengers to select flights, reserve seats, and manage their bookings efficiently. It also manages flight information and seat availability to ensure that the same seat cannot be reserved by multiple passengers. Technologies Used: Java Object-Oriented Programming (OOP) Arrays and Data Structures Visual Studio Code Problem it Solves: Airline booking processes can be complex and time-consuming if done manually. This system simplifies the process by allowing users to easily search for flights and reserve seats while ensuring that seat availability is managed correctly and conflicts are avoided.

Library Managemnent System

The Library Management System is a web-based application developed to manage books, members, loans, and reservations within a library. The system allows administrators or staff to add, edit, search, and delete books, manage member information, and track borrowed books and reservations. Technologies Used: HTML CSS PHP MariaDB (Database) XAMPP Problem it Solves: Traditional library systems often rely on manual record keeping, which can lead to errors and inefficiencies. This system digitizes library operations, making it easier to track books, manage members, and monitor borrowing activities.

Distriuted Endpoint Monitoring System

The Distributed Endpoint Monitoring System is designed to monitor and manage multiple endpoint devices from a central server. Endpoint agents collect system information and send it to a central management server where administrators can view the status of each device, monitor activity, and manage endpoints remotely.
